# HealthVault
Personal Health Management App built with React Native (Expo) and Firebase.

## Setup Local
1. Clona el repositorio: `git clone https://github.com/selinefeliz/healthvault-app.git`
2. Instala dependencias: `npm install`
3. Copia el `.env.example` a `.env` y rellena las variables de Firebase.
4. Ejecuta: `npx expo start`
